# powerbi-sales-dashboard
Amazon Sales Dashboard using Power BI

Developed an interactive Power BI dashboard to analyze Amazon sales data and business performance across different markets, categories, and cities. The dashboard provides insights into sales, profit, quantity, shipping modes, and regional trends using dynamic charts, filters, and visualizations. Implemented data analysis techniques to track category-wise performance, market distribution, and top-performing cities, enabling better business decision-making and trend analysis.

Key Features

Sales, profit, and quantity performance tracking
Market-wise and country-wise sales analysis
Category and city-level visualization
Interactive filters and dynamic charts
Shipping mode performance analysis

Tools & Technologies

Power BI
Data Visualization
Data Analysis
Microsoft Excel
